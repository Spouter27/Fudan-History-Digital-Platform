# B组接入C组接口验证

日期：2026-11-01。接口基线：docs/C组接口契约.md v1.1；后端提交f09dc1b。此记录描述本地实现与验证，不代替团队的契约评审/确认。

## 页面与接口映射

| 页面/功能 | 调用 | 接入行为 |
|---|---|---|
| 时间轴 | GET /api/timeline | 每页8条；时期映射start/end，主题映射category，关键词映射keyword；筛选变化回第1页；年/十年分组作用于当前页 |
| 事件弹窗 | GET /api/timeline/:id | 读取最新详情，显示关联人物与资料；404/失败显示可重试提示 |
| 人物查找 | GET /api/persons | 每页5条，role/keyword筛选；结果按钮选择图中人物，中心模式下同步切换中心 |
| 人物侧栏/弹窗 | GET /api/persons/:id | 侧栏读取人物详情；弹窗使用后端relatedEvents和relations/sourceRef |
| 关系图 | GET /api/relations/graph | 默认全图；支持centerId和depth=1—5；保持SVG拖动、缩放、键盘选择；节点无坐标时提供环形布局 |
| 搜索 | GET /api/search | 每页10条，q/type/page；URL保存条件与页码，切换关键词/类型回第1页；用jumpType/jumpId打开对应详情 |
| 元数据 | GET /api/catalog | 保留来源目录、演示标记、总体统计、人物名称与预置坐标；主页面结果由上述新接口驱动 |

## 实现边界

- C组后端、接口字段和冻结契约未改动；原登录、投稿、审核逻辑保留。
- `catalogRepository.ts`提供HTTP与demo两套同形入口，API请求失败会显示错误，不自动以demo数据替换。
- HTTP沿用统一响应校验、15秒超时和错误处理。C组新增结构均有Zod校验；图边必须指向实际节点。
- 筛选输入有250ms防抖；请求键变化立即隐藏旧结果，并忽略迟到响应。当前通过失效标记防止过期响应写入；请求本身仍受15秒超时约束。
- 搜索高亮不使用innerHTML。只有精确、成对、无属性的`<em>`标记转换成React元素，其余文本由React转义。
- `sourceRef`按逗号拆成来源ID；人物/事件详情的来源使用现有catalog展示。独立来源详情接口不在C组本轮契约内。
- 人物查找筛选控制上方人物列表；下方图谱范围由“关系范围/展开层数”单独控制，保留关联上下文。

## 本地运行

根目录分别运行 `pnpm dev:backend` 和 `pnpm dev:frontend`，访问 http://127.0.0.1:5173/ 。本地后端配置保留DB_DRIVER=sqlite，前端为VITE_DATA_MODE=api、VITE_API_BASE_URL=/api。

检查：根目录 `pnpm check`。切换demo：修改frontend/.env.local中的VITE_DATA_MODE=demo并重启前端；demo入口由自动测试覆盖。

## 后续仍需独立完成

PostgreSQL真实回归、RAG、资料管理和生产部署不属于本次B组接入。保留/catalog意味着当前尚未消除全目录加载的开销，后续若要彻底按需加载，需要与C组约定来源目录/统计等接口。搜索各类型数量目前仅显示当前筛选的服务端total，未伪造全量分类计数。

## 接入协作事项与当前处理

以下是本地接入发现的事项，供B组与C组讨论；尚未对外发送消息，也未修改C组冻结契约。

| 事项 | 影响 | 当前处理/建议确认 |
|---|---|---|
| 来源详情和总体统计尚无独立接口 | 主页面虽然已分页，启动仍需全量/catalog；来源信息是该次加载的快照 | 当前按v1.1保留兼容调用，不阻塞演示。数据增长或需实时来源权限时，协商来源/统计接口及刷新策略 |
| 图接口不含坐标、生平及demo标记 | 图节点本身不足以展示完整人物档案 | 已按契约适配：坐标/展示元数据从catalog补充，缺坐标用环形布局，人物详情另查/persons/:id；无需C组临时改字段 |
| highlight包含<em>字符串 | 直接作为HTML注入会带来脚本/事件属性风险 | 已用React文本转义和精确标记识别处理；后续如需改变高亮格式，走契约变更流程 |
| PostgreSQL配置与验收尚未收尾 | SQLite测试通过不能代表PG已可交付 | 当前DB_DRIVER=sqlite，本地联调已通过；C组补默认驱动、可配置连接、初始化/迁移及PG回归，详见根目录项目检查记录 |

前端关键注释已补充到接口Schema与模式选择、请求失效与防抖、URL查询条件、图谱转换与拖动坐标、详情来源、分页与安全高亮、共创及认证边界，便于按文件职责继续维护。
