# 复旦记忆前端原型

这是《校史数字化共创平台项目计划书》的一期前端实现，供学生团队开发、演示与联调。采用 React + TypeScript + Vite，原计划的时间轴与人物关系图先用 HTML/CSS 和 SVG 实现，减少图表库学习成本。没有修改原计划书。

## 立即运行

安装 Node.js 24 LTS 和 pnpm（本项目在 pnpm 11.19.0 下验证），然后在 PowerShell 中运行：

~~~powershell
cd ./frontend
pnpm install --frozen-lockfile
pnpm dev
~~~

访问 http://127.0.0.1:5173 。请通过本地服务器打开，不要直接双击 index.html。

~~~powershell
pnpm test       # 数据引用、投稿状态、持久化、接口校验等测试
pnpm build      # TypeScript 检查并生成 dist
pnpm preview    # 查看生产构建，http://127.0.0.1:4173
~~~

若端口被占用，可使用 pnpm dev --port 5174；浏览器地址也相应更换。不同端口是不同来源，本地投稿不共享。

## 已实现的内容

| 页面 | 路径（井号后的部分） | 功能 |
| --- | --- | --- |
| 校史时间轴 | / | 12条事件样例，时期与主题筛选、关键词过滤、按年/十年分组、详情与出处 |
| 人物关系 | /people | 8个虚构人物、11条关系，类型筛选、搜索、拖动、缩放、重置、键盘选择、关系出处 |
| 档案侦探局 | /detectives | 3个虚构史料判断任务、预设线索文本、答题反馈与关联资料入口 |
| 资料目录 | /sources | 3条虚构资料登记样例，类型、登记信息、摘录、展示范围 |
| 全站搜索 | /search?q=校园 | 事件/人物/史料检索、中文多词匹配、类型切换、高亮、分页 |
| 记忆共创 | /memories | 表单验证、本地保存、我的投稿、已审核记忆、撤回、删除、JSON导出 |
| 审核演示 | /review | 待审队列、通过、填写原因退回、状态同步 |

详情链接使用 record=event:e1 / person:p1 / source:s1 参数，可复制链接并刷新。弹窗支持 Escape 关闭、焦点限制和关闭后焦点恢复。桌面和窄屏有不同布局。

**所有内置事件、人物、关系、史料均为演示数据，不是考证结果。** 年份仅用于交互测试，引用号没有真实馆藏对应。没有采集个人资料，没有调用外部 AI，也没有使用未经核实的校史照片。

## 五分钟演示

1. 时间轴选“校园生活”，点击卡片，查看详情与出处；清除筛选。
2. 切换“按十年”，再去人物关系页，点选/拖动人物，查看人物档案。
3. 搜索“校园”并切换事件、人物、史料；搜索“江知远”查看虚构人物。
4. 进入“档案侦探局”，完成任一虚构任务，调阅项目内置的“档案助手线索”，并打开关联资料。
5. 进入记忆共创，署名用笔名，填入至少20字的虚构经历，勾选授权并提交。
6. 进入右上角“审核演示”，通过该条投稿。
7. 回到记忆共创 → 共同记忆，确认出现；在我的投稿撤回，确认共同记忆不再出现。
8. 也可以提交另一条并退回，查看审核意见。导出按钮下载当前“我的投稿”的 JSON。

## 当前边界

- 演示使用当前浏览器 localStorage。换浏览器、换端口或清除站点数据后不可共享/找回；不适合多用户正式运营。
- 审核入口是角色视角演示，没有账号、认证或真实权限隔离。
- 退回内容当前可查看意见、撤回、删除和重新投稿，尚无原条目编辑/重新送审。
- 时间轴采用离散分组，没有连续时间缩放和多来源平行泳道；关系图是可交互 SVG 布局，没有自动力导向布局。
- 档案侦探局的三个任务、关联资料和线索文本均为虚构演示；线索文件位于public/detective-responses/，不调用外部AI。
- 只实现一期前端。地图、社群、个人AI记录、AI问答、附件上传不在此版范围。
- API适配器已经写好，但后端尚未实现；切换为api模式后需要真实接口与已建立的登录会话，不会自动退回假数据。

## 接入真实后端

复制 .env.example 为 .env.local：

~~~dotenv
VITE_DATA_MODE=api
VITE_API_BASE_URL=/api
~~~

开发时可将 API 地址改为 http://127.0.0.1:3000/api，并在后端明确放行前端来源及 credentials；推荐正式部署走同源 /api 代理。修改环境变量后重启开发服务；生产构建需要重新执行 pnpm build。

VITE_* 会打包进浏览器，严禁填数据库密码、大模型密钥或邮件服务密钥。

先阅读 [接入与协作手册](docs/接入与协作手册.md)，再依据 [API约定](docs/API约定.md) 实现后端。前端状态检查只改善交互，最终权限和数据校验必须由后端执行。
